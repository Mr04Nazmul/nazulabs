# NAZORIX website

Static NAZORIX Network website, with a progressively enhanced React Lycoris hero.

```sh
npm ci
npm run build
npm test
```

Reusable UI lives in `components/ui`, with Tailwind styles in `styles/lycoris.css`.
See [LYCORIS-INTEGRATION.md](LYCORIS-INTEGRATION.md) for architecture, shadcn setup,
props, local development, and static hosting instructions.
